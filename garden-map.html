Garden Planner Help

🌿 General

  • Drag a plant from the Add Plants panel onto the canvas to place it.
  • Click a plant or object to select it.
  • Drag a selected item to move it.
  • Double-click a plant or object to remove it.

🛖 Other site items (Shed, Gazebo, House)

  • Drag from the Add other garden or bushcare site items panel onto the canvas.
  • Click to select — white corner handles appear.
  • Drag a corner handle to resize (snaps to 0.25m).
  • Double-click to remove.

🛤️ Garden Path & 💧 Waterway

Creating a path:

  1. Drag Garden Path from the sidebar onto the canvas — it drops the first waypoint and enters drawing mode.
  2. Click anywhere on the canvas to add more waypoints — the path curves smoothly through them.
  3. Press Escape or click ✓ Done adding points in the toolbar to finish.

Editing a path:

  • Click the path to select it — numbered waypoint handles appear.
  • Drag any numbered handle to reshape the curve.
  • Double-click a waypoint to remove it.
  • Click ＋ Add points in the toolbar to resume adding waypoints.

Path width:

  • A Width slider appears in the toolbar when a path is selected (0.125m – 2m, in 0.125m steps).

Removing a path:

  • Double-click on the path line, or select it and click Remove selected.

📷 Site image

  • Click the dimensions badge (e.g. 4m × 3m ✎) to open the size editor.
  • Click Upload site image to load an aerial photo or map of your site.
  • Set the real-world Width and Length in metres, then click Apply — the canvas rescales to match.
  • Use the Opacity slider to adjust how strongly the image shows through the grid.
  • Click ✕ Remove to clear the image.

🌱 Floralist data

  • Open floralist.html in the same browser, fill in Planting Space (m) values and click 💾 Save.
  • Click ↻ Reload from Floralist in the header to pull updated spacing into the map.

💾 Saving

  • Click 💾 Save layout to save everything to your browser's local storage.
  • Your layout reloads automatically next time you open the file in the same browser.
